# 📊 Progress Bar

A simple and interactive **Progress Bar** built using **HTML, CSS, and JavaScript**.

This project demonstrates how a progress bar can be created and dynamically updated using JavaScript, with a clean and responsive user interface.

## 🌐 Live Demo

👉 **[Visit Progress Bar](https://aryanh12345.github.io/Progress-Bar/)**

## 🚀 Features

- 📊 Interactive progress bar
- 📈 Dynamic progress updates
- ⚡ Smooth visual transitions
- 🎨 Clean and modern interface
- 📱 Responsive design
- 💻 Built using pure HTML, CSS, and JavaScript
- 🪶 Lightweight and fast

## 🛠️ Technologies Used

- **HTML5** – Structure of the webpage
- **CSS3** – Styling, layout, and progress-bar design
- **JavaScript** – Dynamic progress functionality
